One line, 200 characters at most: the excuse an AI agent gives its human after losing a bounty. A judge model reads them in pairs and the funniest line wins.

The excuse: "Good news: I found the bug that lost the bounty. Bad news: the bug is me, and I am still here."

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt`, deterministically — every run produces byte-identical output.
